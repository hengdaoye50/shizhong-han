## 生平履历

1. 本匈奴休屠王太子。昆邪杀休屠王降汉，日磾没入官，输黄门养马，时年十四。
2. 武帝奇之，拜马监，**迁侍中驸马都尉光禄大夫**，出入骖乘。
3. 察觉侍中仆射莽何罗谋逆，擒之，封秺侯。
4. 武帝遗诏辅政，为车骑将军。不受封，病困，霍光白封，卧受印绶，一日薨。
5. 子赏、建俱侍中；金氏七世内侍。
