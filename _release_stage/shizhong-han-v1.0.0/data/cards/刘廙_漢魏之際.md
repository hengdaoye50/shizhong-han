## 生平履历

1. 字恭嗣，南阳安众人。仕曹操、曹丕。
2. 为魏王**侍中**，禅代前后奏议的主要执笔与宣叙者之一。
3. 与辛毗、刘晔等联名上言，考图纬符瑞，宜顺灵符速践皇阼。
4. 华歆、贾诩、王朗等上言中点出「侍中刘廙等宣叙众心」。黄初二年卒。

## 侍中任职前后

- 魏王侍中；禅代奏议
