## 生平履历

1. 金日磾弟伦之后，**少为侍中**，惇笃有智，宣帝爱之。
2. 与发举楚王延寿反谋，赐爵关内侯。
3. 霍氏反，安上传禁门闼，无内霍氏亲属；封都成侯，至建章卫尉。
4. 与史高建发霍氏事；使谕意萧望之，并诘问望之。
5. 四子：常、敞、岑、明。
