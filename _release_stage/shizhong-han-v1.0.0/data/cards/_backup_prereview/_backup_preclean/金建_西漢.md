## 生平履历

1. 金日磾次子；与兄赏**俱为侍中**，与昭帝略同年，共卧起。
2. 为驸马都尉（兄赏为奉车都尉）。
3. 昭帝时兄弟佩绶事见霍光对话；建嗣侯与否、卒年阙。

## 侍中任职前后

- 迁入：阙（少为近侍，与兄同）
- 迁出：驸马都尉（兼官）
- 与 P0001（父）、P0003（兄赏）构成西汉金氏近侍核心
