## 生平履历

1. 字景倩，颍川颍阴人，荀彧子。少知名，博学洽闻，理思周密。
2. 魏时以父勋为中郎。司马懿辅政，见顗奇之，擢拜散骑侍郎，累迁侍中。
3. 与崔赞、袁亮、钟毓等讲述礼典。武帝使侍中荀顗、和峤至东宫观察太子。
4. 晋受禅，进位公，为太尉、行太子太傅。泰始十年卒，谥康。

## 侍中任职前后

- 魏侍中；晋太尉
