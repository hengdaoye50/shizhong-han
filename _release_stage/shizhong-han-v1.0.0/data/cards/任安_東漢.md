## 生平履历

1. 字定祖，广汉绵竹人。少游太学，受《孟氏易》，兼通数经。
2. 学终还家教授，诸生自远而至。人称「任圣童」。
3. 征拜议郎，**稍迁侍中、弘农太守**。以侍中祭酒卒于官。
