## 生平履历

1. 字叔阳，京兆长安人。父由为太尉。
2. 少传《欧阳尚书》，教授数千人。为汝阴令，号称神父。
3. 迁赵相，入为尚书仆射。顺帝以登明识礼乐，使持节临太学，奏定曲律，**转拜侍中**。
4. 典领秘书近署，甚见纳异。以病免，卒于家。
