## 生平履历

1. 字子鱼，平原高唐人。举孝廉，除郎中，病去官。
2. 何进辅政，征为尚书郎。献帝时拜豫章太守。
3. 曹操表征歆，拜议郎，参司空军事，入为尚书，**转侍中，代荀彧为尚书令**。
4. 魏国既建，为御史大夫。文帝即王位，拜相国，封安乐乡侯。黄初中为司徒。太和五年卒，谥敬侯。
