## 生平履历

1. 字稚都，北海安丘人。习《公羊严氏春秋》。少府。
2. 数月，征为侍御史，再迁尚书令。永平十一年拜光禄勋。
3. 十八年，以病乞身，为**侍中骑都尉**，卒于官。
4. 常卧疾斋宫，妻窥问，泽大怒，收送诏狱。语曰「生世不谐，作太常妻」。
