## 生平履历

1. 伏湛玄孙。袭爵不其侯，尚桓帝女阳安公主，为**侍中**。
2. 女伏寿为献帝皇后。完沉深有大度。
3. 董卓乱中同济唯皇后、杨彪、董承及后父执金吾伏完等数十人。
4. 封辅国将军伏完等十余人为列侯。建安十四年卒。
