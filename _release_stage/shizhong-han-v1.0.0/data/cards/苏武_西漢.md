## 生平履历

1. 字子卿，杜陵人，苏建子。**初，武与李陵俱为侍中**。
2. 天汉元年以中郎将使匈奴，被扣十九年，啮雪吞毡，持汉节不失。
3. 始元六年归，拜典属国，赐爵关内侯。
4. 宣帝时与霍光定策，封关内侯，图形麒麟阁。神爵二年卒。
