## 生平履历

1. 字元礼，颍川襄城人。党锢名士「八俊」之首。
2. 初举孝廉，为青州刺史，守令畏威明，多望风弃官。
3. 再迁**侍中、虎贲中郎将**。出为乌桓校尉、度辽将军。
4. 延熹九年党事起，下狱。永康元年赦归，禁锢终身。建宁二年死于狱。
