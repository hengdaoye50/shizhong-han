## 生平履历

1. 本匈奴休屠王太子；昆邪杀休屠王降汉，日磾没入官，输黄门养马，时年十四。
2. 武帝游宴见马，拜马监，**迁侍中驸马都尉光禄大夫**；出入骖乘，甚见信爱。
3. 与霍光、上官桀共诛莽何罗（马何罗）兄弟；以发觉侍中莽何罗反封秺侯。
4. 武帝遗诏辅政，为车骑将军；不受封，病困，霍光白封，卧授印绶，一日薨。
5. 母教两子有法度；杀淫乱弄儿（长子），上哀而敬之。
