## 生平履历

1. 章德皇后弟；和帝即位时为**侍中**，以外戚之重干预朝政与教育。
2. 荐张林为尚书；与陈宠等冲突；刺杀齐殇王子都乡侯畅。
3. 永元元年，以侍中为车骑将军，伐北匈奴；后迁大将军。
4. 威权倾朝；女弟婿郭举亦为侍中。永元四年败，自杀。

## 侍中任职前后

- 迁入：外戚近侍（细节另核）
- 迁出：侍中 → 车骑将军（本纪有明文）
