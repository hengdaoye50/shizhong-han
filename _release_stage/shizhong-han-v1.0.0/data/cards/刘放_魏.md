## 生平履历

1. 字子弃，涿郡方城人。汉广阳顺王子西乡侯后。举孝廉。
2. 太祖辟为参司空军事。魏国既建，与孙资并为秘书郎。
3. 文帝即位，放、资转为左右丞。**为侍中、中书监**，典机密。
4. 明帝即位，加散骑常侍。齐王即位，加左右光禄大夫。正始七年卒，谥敬侯。
