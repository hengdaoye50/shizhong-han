## 考据原则

1. **可考则卡**：有事迹句（如君卿赐金）必建卡，标佚姓。  
2. **不可考则表**：仅有「遣侍中某」而无名无事，进本表，不建空卡。  
3. **不硬合并**：同名不同传，先分卡再校。  
4. **OCR/镜像残字**（周BC60）以维基/正史本校正后并入。
