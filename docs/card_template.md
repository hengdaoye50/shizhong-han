# 人物卡片字段模板

一人一文件：`data/cards/<姓名>_<朝代>.md`  
朝代取值：西漢 / 新 / 東漢 / 漢魏之際

## 状态

- `草稿`：机器或初筛生成，未校
- `待审`：已填关键字段，待人对照原文
- `已校`：可进正式库（引用、图谱、统计）

**只有「已校」条目进入 SQLite 与关系图。**

## 模板

```markdown
---
id: P0001
name: 金安上
style_name: 子侯
dynasty: 西漢
status: 待审
category:  # 士人|外戚|宦官|降人|宗室|其他，可多选逗号分隔
origin:    # 籍贯，如 匈奴休屠→长安
birth:     # 约年或阙
death:     # 约年或阙
shizhong_terms:
  - start:   # 年号纪年或公元，可空
    end:
    nature:  # 加官|正职|出入禁中|复合官（侍中仆射等）
    evidence: 有明文|推断|阙疑
sources:
  - book: 漢書
    juan: 卷068
    quote: 「安上字子侯，少為侍中……」
---
```

## 编码约定

- `id`：`P` + 四位顺序号，试点从 `P0001` 起
- 原文引用保留史书用字（可繁可简，但同一卡片内统一）
- 纪年：优先年号，括号注公元；不确定写「约」或「阙」
- 与 CSV 候选对应：在备注里写 `cand:` 行号或 source_file
